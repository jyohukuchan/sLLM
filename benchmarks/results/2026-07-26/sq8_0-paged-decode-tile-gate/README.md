prompt groups: prompt lengths 127/128, producing decode cache lengths

boundaries and non-multiple tail shapes.  Three actual M=1 decode feedback

## Throttle evidence and measurement applicability

During the 240 one-second samples, amd-smi reported THROTTLED 119 times
and UNTHROTTLED 121 times.  Recorded sampled ranges were socket power
8--260 W, gfx clock 2--3427 MHz, edge temperature 36--57 C, hotspot
37--76 C, and memory temperature 34--60 C.  The configured PPT0 limit was
300 W (reported range 210--330 W); slow thermal limits were edge/hotspot
110 C and VRAM 108 C.

The raw GPU-metrics v1.3 throttle fields identify hotspot thermal status
(0x2 dependent / bit 36 independent) in the samples, and one dependent
sample also contains PPT0 (0x4002; independent status has bit 0 together
with bit 36 once).  No TDC bit was observed.  AMD SMI itself reported its
per-reason/violation fields as unsupported (N/A).  The two raw fields were
read separately, so they are not an atomic paired observation; a sampled
temperature/power value can also miss a transient peak.  Therefore the
physical sustained cause is **未確認**: the status evidence supports hotspot
status and one possible PPT0 event, but does not prove that the sampled
46--76 C temperatures or 8--260 W powers were the limiting instantaneous
condition.

The prior low-temperature THROTTLED observation cannot be retrospectively
assigned a unique cause.  Timing rankings from a window containing these
states should be treated as conditional and rerun under a stricter telemetry
guard.  This does not explain away the numerical failure: a frequency/power
throttle can affect timing but is not an expected explanation for deterministic
full-model vector divergence.

throttle-summary.json records the decoded evidence and caveats.  The
recommendation for a later timing window is an atomic single-read metrics
capture, a cool-down/all-clear gate, and discard/repeat policy when a
throttle-reason bit appears.  No permanent power-cap or policy change was
performed.  Tile 64/96 exploration was not run because it would require an
additional window and the required numerical gate already failed.
